# study-javascript

Webサイトでよく使うUIパーツを、JavaScript（フレームワークなし）で実装した学習用リポジトリです。

## 使用技術

HTML / Sass / JavaScript

## 実装したUIパーツ

- ハンバーガーメニューの開閉
- ホバーで開くドロップダウンメニュー
- タブの切り替え
- アコーディオン
- モーダル

## 実装したフォームの補助機能

- セレクトボックスやラジオボタンの選択内容に応じた入力欄の表示・非表示
- 全角英数字を半角に変換
- メールアドレスの確認入力の一致チェック
- 電話番号のハイフンを自動で削除
- 画像を選択したときのプレビュー表示
